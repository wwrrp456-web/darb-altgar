# 🐪 درب التجّار

لعبة استراتيجية تجارية بالمتصفح: قافلة وأسواق وإمبراطورية تمتد من مصر إلى الصين.

**العب الآن:** https://wwrrp456-web.github.io/darb-altgar/

## التثبيت على الجوال
- **أندرويد (كروم):** القائمة ⋮ ← «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية».
- **آيفون (سفاري):** زر المشاركة ← «إضافة إلى الشاشة الرئيسية».

يعمل دون اتصال بعد أول فتح، ويُحفظ تقدّمك في متصفح الجهاز.

## التطوير
```
node build.js          # يبني index.html وsite/ وdist-artifact.html
node test/screens.test.js   # اختبارات الواجهة (Playwright)
node test/bosses.test.js    # اختبارات المحرك
```
- `src/engine.js` المحرك، `src/ui.js` الواجهة، `src/template.html` القالب والأنماط.
- `src/world-map.js` حدود الخريطة والمسارات والرقع الفنية؛ [دليل إضافة الدول وتوسيع الخريطة](docs/WORLD_MAP.md).
- [الخريطة ثلاثية الأبعاد](docs/CODEX_3D_MAP.md): المرحلة الأولى متاحة كمعاينة اختيارية بزر «ثلاثي الأبعاد»، برسومات قلاع وجمل مفرغة وعمق هادئ للخريطة؛ [التقرير والقياسات](docs/MAP3D_STAGE1.md). المسطح يبقى افتراضياً إلى حين مراجعة النموذج، وتتبع الرحلات على المجسّمات للمرحلة التالية. يتوفر عرض مرسوم خفيف عند تعذّر تسريع الرسومات؛ [تقرير إصلاح التوافق والتحكم](docs/MAP3D_TROUBLESHOOTING.md).
- [مهمة رسومات كودكس](docs/CODEX_ART_TASKS.md): قائمة كاملة بالرسومات الجديدة (مواشٍ وسلع وأحداث وواجهات ومشاهد وشخصيات) بالهوية المعتمدة، تُسلَّم في `brand/next/` ولا تدخل البناء قبل المراجعة.
- [مهمة رسومات كودكس ٢](docs/CODEX_ART_TASKS_2.md): أصناف المواشي (٤٠ صنفاً) وواجهات التنويع والملحمة وأقسام السوق وقرار اليوم. و[خطة العمل والحالة](docs/ROADMAP.md): ما أُنجز وما بقي.
- [مهمة كودكس ٣](docs/CODEX_TASKS_3.md): رسوم المساومة والدفتر ومشهد الرياض التجريبي وتعابير الشخصيات، ووحدتا الأصوات ورمز الحفظ، ومسودة الإنجازات.
- [مهمة كودكس ٤](docs/CODEX_TASKS_4.md): أصول المرحلة ٥، والقافلة المتحركة، وأيقونات الإنجازات الأربعين، ومشاهد المدن الـ١٥ وتعابير زعمائها، ورسوم متجر Google Play.
- `src/icons.js` ربط رموز الواجهة بأيقونات الهوية؛ [دليل الأيقونات](brand/ICONS.md).
- `brand/img/` الرسومات (تُدمج في الصفحة عند البناء)، و`brand/PROMPTS.md` برومتات توليد الصور.
- `pwa/` ملفات التثبيت (manifest وservice worker وأيقونات).
- يُنشر الموقع من جذر فرع `main` (Pages: Deploy from a branch)، لذا يُرفع `index.html` المبني مع ملفات التثبيت في الجذر بعد كل `node build.js`.
