```

## المهمة (رقم: K-__)

## السياق (مكتفٍ بنفسه)

## القيود (لا تُكسر)
- مخرَج واحد: ملف باسم `<الاسم>.<الامتداد>`، أرسله كملف أو كتلة شيفرة واحدة كاملة.

- ممنوع: رسومات أو صور، أي آية أو حديث أو حكم شرعي، بريد أو مفاتيح، وكتابة منطق اللعبة.
- الأيقونات إيموجي مؤقتة.
```
