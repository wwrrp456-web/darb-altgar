# بناء دليلي درب التجّار

التسليم: `player.html` للجوال، و`player.pdf` للتحميل، و`dev.pdf` للمبرمج فقط. وسيط المبرمج `src/dev.html` داخلي ولا يُنشر. المصدر البرمجي الموثّق: `78a1d20`؛ تاريخ البناء 2026-10-21.

## البناء والتصوير

من جذر المشروع، باستخدام Node وChromium ونسخة Playwright المتاحة في البيئة:

```sh
node scripts/build-guides.js --check
node scripts/build-guides.js --shoot --check
```

الأمر الثاني يعيد تصوير اللعبة محليًا ثم يبني. لا يُنزّل المولد حزمًا أو خطوطًا، ولا يشغّل `build.js`، ولا يعدّل ملفات اللعبة أو صور `brand/`. عند الحاجة حدّد `GUIDE_PLAYWRIGHT_PATH` لمسار Playwright الموجود و`GUIDE_CHROMIUM_EXECUTABLE` لمسار Chromium. اختبرت هذه النسخة باستخدام `/workspace/cloud-tools/node_modules/playwright` و`/usr/bin/chromium`.

## التحديث

حرّر فصول `src/player.json` و`src/dev-*.json`. راجع الشيفرة أولًا، ثم حدّث `facts.json` و`reference.json` بعد التأكد؛ يرفض البناء ثوابت أو بيانات لم تعد تطابق المحرك. حدّث النسخة والتاريخ ورقم مراجعة اليوم في `src/meta.json`. لا تضع `ready: true` إلا بعد اكتمال فصول اللاعب؛ يولد السكربت علامة الجاهزية منها.

أضف سطورًا إلى `CHANGELOG.md` بصيغة `- [لاعب] YYYY-MM-DD: النص` أو `[مبرمج]`. يولّد البناء آخر 20 سطرًا لكل جمهور في فصل التغييرات الخاص به. اكتب «للتأكد» عند بقاء غموض، وسجّله في `VALIDATION.md`. أعد قياس الضغط بالأمر `node test/stress.js` وحدّث `src/economy-baseline.json` من النتيجة الفعلية.

## النشر

يجهّز **بناء اللعبة** دليل اللاعب الجاهز عبر `pwa-guide/` وينسخه إلى `guide/` و`site/guide/`؛ مصدر المحتوى هنا وسياسة أمانه لا تُعدّل لأجل التثبيت. المبرمج لا يُنشر. **البناء الحالي لا ينسخ `player.pdf`**: يلزم عند النشر نسخ ملفنا إلى `guide/player.pdf` و`site/guide/player.pdf` ليعمل زر التحميل. PDF لا يدخل قائمة التخزين الأولية للخدمة؛ يحمله اللاعب وهو متصل. هذه المهمة لم تعدّل أيًا من ملفات النشر أو اللعبة المحمية. تحقق دمجنا من بناء نسخة مؤقتة فقط، لا من نشر حي.

## الملفات المنتجة

- التسليمات الثلاثة أعلاه، و`README.md` و`CHANGELOG.md` و`VALIDATION.md`.
- `img/`: 27 لقطة WebP فعلية بعرض 390 و1280، و14 نسخة مصغرة من أصول الهوية؛ المصادر الأصلية لم تتغير.
- `src/`: فصول المحتوى، القالب والقراءة والطباعة، مرجع البيانات وخط الأساس، أدلة التشغيل والتصوير وفحوص الجودة، ووسيط المبرمج.
- `scripts/build-guides.js`: المولد. القائمة التفصيلية للأسماء والأحجام في `src/inventory.json`، وتقرير الصفحات في `src/build-report.json`، وحدود التحقق في `VALIDATION.md`.
