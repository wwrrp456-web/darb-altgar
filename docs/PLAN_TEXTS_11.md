# خطة تطبيق مراجعة النصوص والإثراء (٢٢ أكتوبر ٢٠٢٦)

## مهام Claude
1. **الدفعة ١:** أدوات الفحص (حدّ الأطوال، سلامة الرموز والأرقام، مقارنة قبل/بعد)، ثم تطبيق نحو ٢٧٥ نصاً أدبياً ونحو ٥٢ نصاً شرعياً مقفلاً بعد قراءة فرق كل نص (لا تُطبَّق نصوص الواجهة المبنية بالكود، ولا الأزرار والعناوين المتضخمة، ولا ما غيّر المعنى كحكاية العمل وحكاية الإقراض).
2. **الدفعة ٢:** تعريف الشخصيات عند أول ظهور، والجسور بين ذكرى الجدّ وحكاية الحكمة، وربط ملفات كودكس (حِكَم الطريق، خاتمة الحكمة، المهمتان) باللعبة، ونازلة العربون في `fiqh.js` بالنسق الجديد (الخلاف ثم المجمع ثم المعتمد).
3. **الدفعة ٣:** «رصيد البركة» (خلف مفتاح تجريبي مع `stress`)، وقفل السفر بالمستوى بعد اعتماد المالك، وتحديث `CHANGELOG`، والحزمة الكاملة والدفع.

## مهام كودكس (`docs/CODEX_TASKS_11.md`)
1. `src/tips.js`: حِكَم الطريق (٨ أحاديث + أثر + ١٠ حِكَم).
2. `src/stingers.js`: خاتمة الحكمة للمستويات العشرة.
3. `src/quests-extra.js`: قافلة الحج وإعانة التاجر المعسر.
