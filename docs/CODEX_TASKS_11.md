# مهمة كودكس (١١): ثلاثة ملفات بيانات جديدة للإثراء (حِكَم الطريق، خاتمة الحكمة، مهمتان جانبيتان)

**اقرأ هذا الملف كله ثم نفّذ المهام ١ ثم ٢ ثم ٣ بالترتيب**، كل مهمة في commit مستقل، وادفع بعد كل واحدة قبل أن تبدأ التالية. أنت تكتب **ملفات بيانات فقط**؛ الربط بالواجهة والمحرك يتولاه Claude في الوقت نفسه، فلا تقترب من ملفاته.

مصدر الأفكار: تقرير المراجع اللغوي (إضافاته المقترحة)، وتوثيق شواهده في `docs/review/SOURCES.md` (التخريج المؤكَّد، وما فيه «يُراجَع» لا يدخل).

## قواعد عامة (ملزمة)

1. **ملفات جديدة فقط**: `src/tips.js`, `src/stingers.js`, `src/quests-extra.js`. **ممنوع تعديل** أي ملف آخر (خصوصاً `src/lessons.js`, `src/babylon.js`, `src/lore.js`, `src/dialogs.js`, `src/fiqh.js`, `src/cards.js`, `src/engine/*`, `src/ui/*`, `build.js`, `test/*`, `index.html`, `brand/*`). ولا تضفها إلى `build.js` أو `test/*`؛ هذا عملي.
2. **نمط الوحدة** كبقية ملفات البيانات: `(function (root) { 'use strict'; ... const API = {...}; if (typeof module !== 'undefined' && module.exports) module.exports = API; else root.Tips = API; })(typeof window !== 'undefined' ? window : globalThis);` (الاسم العام: `Tips` و`Stingers` و`QuestsExtra`). افتح `src/dialogs.js` و`src/cards.js` كنموذج.
3. **لا تختلق شرعاً ولا تاريخاً.** الأحاديث والآثار **حرفياً** من `docs/review/SOURCES.md` مع تخريجها في حقل `s` كما في `src/cards.js` (حقل `dalil`: `{ q: النص, s: «متفق عليه» أو «رواه الترمذي» }`). لا تضف حديثاً ولا أثراً ولا حكماً من عندك، ولا تعدّل لفظاً. وما هو «يُراجَع» في ذلك الملف لا تستعمله.
4. **ممنوع في النصوص**: «بابل» وأسماء الكتاب الأصلي (داباسير، ماثون، أركاد…)، والأقواس المعقوفة `{…}` (اختبار `textlint` يرفضها)، والأرقام العربية الهندية (استعمل 0-9)، والإيموجي (اختبار `icons` يرفض الرموز غير المسجلة)، و«في لعبتنا» وأي كسر للجدار الرابع، والعامية، وأي لفظ يحقّر الإنسان. اقرأ `docs/NAMES.md`: **لا اسم علم جديد إلا من الجدول فيه** (والمقرض الحكيم اسمه «الحكيم صادق» وهو غير الدائن «الحاج صالح الصيرفي»).
5. **اللسان:** فصحى مبسطة يفهمها ابن ١٢ سنة وأبوه، دافئة، بلا وعظ ثقيل. عمّ سالم يخاطب اللاعب بـ«يا ولدي».
6. قبل الدفع: `git pull --rebase origin main`، ثم `node -e "require('./src/<الملف>.js')"` للتحقق من سلامة التحميل، ثم `node test/textlint.test.js` إن أمكن (لن يفحص ملفاتك قبل ربطها لكنه شرط عام)، والدفع إلى `main` مباشرة بلا PR. رسائل الـcommit بالعربية.
7. لا تذكر اسم نموذج الذكاء في الـcommit.

## المهمة ١: `src/tips.js`، حِكَم الطريق

تظهر للاعب في شاشة السفر وبطاقة التحميل: جملة قصيرة تتبدل مع كل رحلة.

الشكل المطلوب:
```js
const TIPS = [
  { id: 'sidq', kind: 'hadith', theme: 'الصدق', text: '…', s: 'رواه الترمذي' },
  { id: 'tadbir', kind: 'hikma', theme: 'حفظ المال', text: '…' },
];
const API = { TIPS };
```
- **الأحاديث (`kind: 'hadith'`)**: الثمانية الواردة في `SOURCES.md` (رقم ١ إلى ٨) كلها، **بنصها الوارد هناك**، وحقل `s` للتخريج المختصر («متفق عليه»، «رواه البخاري»، «رواه الترمذي»…). الحديث الثامن (استئجار ابن أريقط) طويل فاختصره بالموضع الوارد في الملف نفسه ولا تضف شيئاً.
- **الأثر**: أثر عمر في الترمذي برقم 487: `kind: 'athar'`، ونصه وحقل `s`: «أخرجه الترمذي برقم 487 وقال: حسن غريب» (دون عنوان الباب).
- **الحِكَم (`kind: 'hikma'`)**: عشر عبارات قصيرة (٦٠ حرفاً أو أقل) من تأليفك عن: حفظ المال، استثمار الأرباح، التدبير في الرخاء، الصبر في الصفقة، قراءة الأسعار، تنويع البضاعة، الوفاء بالعهد. **ممنوع** أن تنسبها إلى النبي ﷺ أو صحابي أو عالم؛ هي حِكَم اللعبة مجهولة النسبة. ولا تكتب فيها حكماً شرعياً.
- حقل `theme` كلمة أو كلمتان للتصنيف، وحقل `id` ASCII فريد.
- المعيار: ٨ أحاديث + ١ أثر + ١٠ حِكَم على الأقل، وكل نص ≤ ١٤٠ حرفاً عدا الحديث الثامن (≤ ٢٠٠)، وبلا تكرار.

## المهمة ٢: `src/stingers.js`، «خاتمة الحكمة» لكل مستوى

بيت مسجوع أو حكمة موجزة تظهر أسفل بطاقة إتمام كل درس من المستويات العشرة. مفتاحها رقم المستوى (١ إلى ١٠)، وموضوع كل مستوى في `src/lessons.js` (`LEVELS[n].title`: قراءة السعر، هامش الربح، التكلفة الواصلة، الجمارك، التنويع، العملات، المخزون، الشراكات، الوكالة، التمويل المشروع). الشكل:
```js
const STINGERS = { 1: 'اقرأ السعر قبل أن تدفع، يُدرك ربحك من يتتبّع.', 2: '…' };
const API = { STINGERS };
```
- لكل مستوى سطر واحد (≤ ٩٠ حرفاً) **يلخص فكرة درسه** (اقرأ الدرس وذكرى الجدّ في `lessons.js` و`babylon.js` لتطابقه)، بسجع خفيف بلا تكلف.
- **لا شرعيات**: لا حديث ولا آية ولا حكم، حتى في مستويي ٨ و١٠ (المضاربة والتمويل): اكتب فيهما حكمة تجارية عامة (الشراكة والصدق والوضوح) دون ذكر أحكام العقود.
- المعيار: عشرة أسطر لعشرة مستويات، بلا تكرار لفظ سجع بين مستويين متجاورين.

## المهمة ٣: `src/quests-extra.js`، مهمتان جانبيتان بنسق `QUESTS`

اقرأ `QUESTS` وحوار `q_coffee` في `src/dialogs.js` (مشهد التاجر في الرياض) كنموذج دقيق: حقول المهمة (`city`, `title`, `need: [سلعة, كمية]`, `pay`, `text`) وعقد الحوار (`q_offer`, `q_active`) بشروطه وآثاره المعرَّفة أعلى الملف.
1. **قافلة الحج** (`q_hajj`): تاجر في مكة المكرمة (`city: 'mecca'`) يطلب كمية من القمح والتمر (اختر سلعة واحدة موجودة في اللعبة وحدّدها من `src/engine/01-data-world.js` أو `GD`) لقافلة الحجيج على درب زبيدة، ويدفع فوق سعر السوق. الشرط: المستوى ≥ ٤.
2. **إعانة التاجر المعسر** (`q_debtor`): تاجر مبتدئ في مدينة من مدن بلد البداية الأول (الرياض) تعثّر في سداد ثمن بضاعة اشتراها منك (حدّد السلعة والمبلغ). **الحوار فيه قرار أخلاقي بثلاثة خيارات**: أمهله (إنظار)، أسقط عنه جزءاً (وضع)، أو طالبه حالاً. لكل خيار أثره بحسب أفعال الحوار المتاحة (`trust`, `pay`, `flag`, `react`)، بحيث الإنظار والوضع يرفعان ثقة التاجر والزعيم بك قليلاً، والمطالبة الفورية تعيد مالك كاملاً وتخفض الثقة قليلاً. ولا تضف ذكراً لحديث أو حكم؛ وتعليق عمّ سالم (إن أردته) بلا نسبة شرعية.
- الشكل: `const QUESTS_EXTRA = { q_hajj: {…}, q_debtor: {…} }` و`const DIALOGS_EXTRA = { <مفتاح الحوار>: { who, city, start, nodes } }` بنسق `DIALOGS` نفسه، و`const API = { QUESTS_EXTRA, DIALOGS_EXTRA }`.
- **لا تعدّل `dialogs.js`**: أنا من يدمجها (قد أعدّل حقولاً لتناسب المحرك). فقط التزم بشروط الحوار وآثاره الموجودة فعلاً ولا تخترع نوعاً جديداً منها.
- نصوص الحوار قصيرة، وكل `say` ≤ ١٨٠ حرفاً، وكل خيار للاعب ≤ ٣٥ حرفاً (يظهر زراً على الجوال).
- المعيار: يُحمَّل الملف بلا أخطاء، وكل مفتاح شرط أو أثر يستعمله موجود فعلاً في `dlgOk`/`dlgDo` (`src/engine/14-dialogs.js`).
