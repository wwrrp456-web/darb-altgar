# اقتراح تصنيف القطع الأساسية في الفصول ٤–٧ (لبن محمود)

**اقتراح غير نهائي**: قد تغيّره جلسات التجربة. مولَّد بـ`node tools/content-map-report.js` (والخريطة الحالية لم تُغيَّر بعد). غرضه: الفصل ٤ مزدحم (112 قطعة) والفصول ٥–٧ رقيقة (31 و35 و11) وقطع المراسي فيها تخمين.

| القطعة | الفصل المقترح (الحالي) | سبب الاقتراح |
|---|---|---|
| `level:8` الشراكات والمضاربة | **4** (4) | يبقى: موضوعه الشراكات والمضاربة، وفيه تُفتح شراكات الزعماء (FEAT_LV.pact = 8). |
| `level:9` الوكالة والتوسع | **6** (4) ← يتغير | موضوعه الوكالة والتوسع، وفيه يُفتح الوكيل (FEAT_LV.agent = 9)؛ والخطة الأم تضع «الأمين والوكيل» في ف٦ (الإدارة عن بُعد). |
| `level:10` التمويل المشروع | **4** (4) | يبقى (أو ف٥ بقرارك): موضوعه التمويل المشروع (ف٤)، لكن المزرعة والمصنع يُفتحان عنده (FEAT_LV.farm/factory = 10) فيصلح مدخلاً لـف٥. |
| `stage:10` رأس المال والعمل | **4** (4) | يبقى: رأس المال والعمل = جوهر الشراكة. |
| `stage:11` توزيع المخاطرة | **4** (4) | يبقى: توزيع المخاطرة في الشراكات. |
| `stage:12` وضوح شروط العقد | **4** (4) | يبقى: وضوح شروط العقد (الشراكة والدَّين). |
| `stage:13` الوكيل في الآفاق | **6** (4) ← يتغير | الوكيل في الآفاق: إدارة عن بُعد (ف٦) لا شراكة. |
| `stage:14` أمانة الوكيل | **6** (4) ← يتغير | أمانة الوكيل: من الإدارة عن بُعد. |
| `stage:15` أجر الوكالة | **6** (4) ← يتغير | أجر الوكالة: من الإدارة عن بُعد. |
| `stage:16` صيغ التمويل المشروع | **4** (4) | يبقى: صيغ التمويل المشروع (مضاربة ومرابحة وقرض حسن) = موضوع ف٤. |
| `stage:17` هامش أمان السداد | **4** (4) | يبقى: هامش أمان السداد = «الوفاء» في ف٤. |
| `stage:18` تحويل المال بأمان | **6** (4) ← يتغير | تحويل المال بأمان (السُّفتجة بين البلاد): موضوعه الأقاليم والعملات (ف٦). |
| `card:g_farm` المزرعة والمواشي والتكاثر | **5** (5) | يبقى مرساة ف٥ (المزرعة)؛ ولا مرحلة ولا مستوى للمزرعة، فهذا فراغ يحتاج محتوى جديداً. |
| `react:buildFarm` buildFarm | **5** (5) | يبقى مرساة ف٥: أول تعليق بعد بناء المزرعة. |
| `card:g_sea` السفر بحراً | **6** (6) | يبقى مرساة ف٦ (البحر). |
| `react:buyShip` buyShip | **6** (6) | يبقى مرساة ف٦: أول تعليق بعد شراء سفينة. |
| `stage:21` الاستقلال المالي | **7** (7) | يبقى: الاستقلال المالي = بداية ف٧. |
| `stage:22` مسيرة حرة | **7** (7) | يبقى: مسيرة حرة = خاتمة ف٧. |
| `tablet:freedom` لوح الحرية المالية | **7** (7) | يبقى: لوح الحرية المالية. |
| `tablet:free` لوح الروح الحرة | **7** (7) | يبقى: لوح الروح الحرة (بعد سداد دَين الجدّ). |

**الأثر:** 5 قطع أساسية تنتقل (المستوى ٩ والمراحل ١٣ و١٤ و١٥ و١٨ إلى ف٦)، فيقل ف٤ بخمس قطع فقط.

**تنبيه:** نقل الأساسي وحده لا يعالج ازدحام ف٤؛ الكتلة الأكبر غير أساسية: 23 مسألة (صعوبة ٢) و19 حكمة و18 حكاية زعيم (الفصل الثاني من حكاياتهم). وإن أردتَ علاج الازدحام فعلاً فالقرار على هذه الأنواع (مثلاً توزيع المسائل على ف٣ وف٥، أو جعل الحِكَم مرافقة لكل الفصول) وليس على الأساسي.

**ما ينقص فعلاً (محتوى لا تصنيف):** ف٥ بلا درس ولا مرحلة (مرساتان فقط)، وف٦ بلا مسائل ولا إنجازات، وف٧ بلا بطاقات ولا إنجازات.
