# مهمة فايبل القادمة (طلب بن محمود 2026-11-12، تبدأ بكلمة «ابدأ» حين يرجع الليميت)

**الاسم:** 047 «مسح التكرار والصوري ونقلة الاندماج».

## المطلوب (ثلاثة أقسام، تقرير واحد)
1. **مسح التكرار:** حصر كل عنصر مكرر بين الصفحات (بطاقة أو زر أو قسم أو رقم يظهر في أكثر من شاشة بلا فرق)، وكل ما يزيد عدد الخطوات في آلية اللعب بلا حاجة. لكل عنصر: أين يتكرر، وهل له لازمة، وتوصية (يُحذف / يُدمج / يبقى بسبب).
2. **مسح الصوري (تكملة `docs/audit/LIVE_GAME_AUDIT_2026-11-10.md`):** كل عنصر موجود كصورة أو اسم فقط بلا أثر ولا فعل للاعب (أيقونة بلا وظيفة، اسم بلا بيانات، شاشة بلا قرار). توصية الحذف أو الربط بأثر.
3. **اقتراحات الاندماج:** ما يجعل اللاعب يقضي وقتاً أطول ويندمج (أدوات تفاعلية داخل اللعبة، حلقات قصيرة ذات مكافأة، تقدم مرئي، مفاجآت موزونة)، مرتبة بالأثر والكلفة، مع نموذج HTML لأهم اقتراح.
