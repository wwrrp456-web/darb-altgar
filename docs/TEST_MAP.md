# مشغّل الاختبارات وفاحص النصوص

## التشغيل

```sh
node test/run.js
node test/run.js market finance --jobs 4 --timing
node test/run.js --changed
node test/run.js --serial --timing
node test/textlint.test.js
```

يقرأ المشغّل قائمة `for t in ...; do` من `test/all.sh` نفسه. القائمة عند التسليم تضم 93 اختبارًا، رغم ذكر 94 في وصف المهمة. لا يضيف الفاحص الجديد إلى القائمة ولا يغيّرها؛ يبقى `textlint` اختبارًا مستقلًا حتى الدمج. لا اعتماديات للمشغّل خارج Node وGit وأمر `timeout` الموجودين أصلًا؛ فاحص النصوص يستعمل مسار Playwright المعتمد في المشروع.

الكلمات مرشحات جزئية بمنطق «أو». `--changed` يجمع التغييرات المرحّلة وغير المرحّلة مقابل `HEAD` والملفات غير المتتبعة غير المتجاهلة؛ يعامل إعادة التسمية كحذف وإضافة حتى لا يفقد ربط المسار القديم. يُطبّق مرشح الكلمات بعد اختيار التغييرات. الملف المجهول أو الربط `"*"` يشغّل الحزمة كاملة؛ القائمة الفارغة تعني عدم الحاجة إلى الاختبارات. عدم وجود كلمات مطابقة خطأ، أما عدم وجود تغييرات فنتيجة معلنة بلا اختبارات.

تُفحص صحة أسماء الاختبارات والروابط قبل التشغيل. يحافظ المشغّل على مهلة 200 ثانية وشرط الفشل نفسه في `all.sh`: رمز خروج غير صفر، أو `^FAIL`، أو `ERRORS:`، أو `pageerror`. يكتب المخرجات إلى `/tmp/t_<name>.out`، ويعرض أول ثلاثة أسطر أخطاء، ويخرج بغير صفر عند الفشل أو الإيقاف. الافتراضي أصغر القيمتين: 4 وعدد الأنوية المتاحة. `--serial` يفرض عملية واحدة ولو وُجد `--jobs`.

## مصدر الربط وحدوده

الربط في `test/map.json`. فُحصت الاستيرادات وقراءات الملفات، ثم استُخدمت أسماء الأنظمة واستدعاءاتها في الاختبارات لتوسيع الربط غير المباشر. مسار كل ملف اختبار مربوط بنفسه؛ `engine.js` وأجزاء `src/engine/*` و`build.js` ومشغّل الاختبارات وخريطته وقائمته مربوطة بالكل. الملفات المجهولة لا تُهمل. `*` في مفاتيح المسارات يطابق بقية المسار، بما فيها المجلدات الفرعية.

الروابط المباشرة المؤكدة تشمل `world-map.test.js → world-map.js`، و`sound.test.js → sound.js`، و`savecode.test.js → savecode.js`، وقراءة `goods` و`animals` لأصول السلع وسجل الأيقونات، وقراءة `update` للصفحة و`sw.js` و`version.json`. يقرأ `numerals` جميع ملفات المصدر، لذلك أضيف إلى كل ربط لمصدر معروف. يقرأ `icons` نصوص `ui` و`template` و`engine` و`lessons` و`lore` و`babylon`؛ أُخذت هذه القراءة في الحسبان.

الروابط التالية استدلالية وليست تحليل اعتماد كامل؛ يجب مراجعتها عند إضافة نظام أو مسار جديد:

| المسار | سبب الاختيار وحدود اليقين |
|---|---|
| `src/ui/*`، `src/template.html`، `index.html` | جميع اختبارات المتصفح؛ الصفحة تجمع الأنظمة. بقي ربط اسم `src/ui.js` السابق للتوافق مع فروق الحذف وإعادة التسمية. يشمل `index.html` أيضًا اختبار تحديث البناء ضمن هذه المجموعة. |
| `src/icons.js` | جميع اختبارات المتصفح و`goods` و`animals`؛ قد تتأثر عناصر خارج شاشة الاختبار المباشر. |
| `src/cards.js` | البطاقات وواجهتها والتعلّم والرحلة واللعب الحر والطبقات؛ بقية الاختبارات لا تختبر البطاقة مباشرة. |
| `src/achievements.js` | الإنجازات وواجهتها والرحلة واللعب الحر والمدن؛ التغطية قائمة على استعمال النظام. |
| `src/lore.js` | الحكايات وقصص الشخصيات والحوارات والساحات والمدن والزعماء والرحلة؛ مع فحص الأيقونات. |
| `src/dialogs.js` | الحوارات والساحة والمدن وقصص الشخصيات والطبقات؛ مخرجات `cityDialogs` تُنشأ عند التحميل. |
| `src/lessons.js` | التعلّم والرحلة والبداية والإرشاد والحكايات والكتابة واللعب الحر والطبقات؛ مع فحص الأيقونات. |
| `src/babylon.js` | الحكايات وتوطين البداية والدروس والرحلة والزكاة وكتابة عمّ سالم؛ مع فحص الأيقونات. |
| `src/world-map.js` | بيانات العالم والواجهة والأسماء وحركة القافلة والمجسّمات وفق الملف؛ قد تتطلب إضافة استعمال جديد توسيع الربط. |
| `src/sound.js`، `src/savecode.js` | اختبار النظام وواجهته، إضافة إلى `numerals` لقراءة ملفات المصدر. |
| `brand/img/*`، `brand/lazy/*`، `img/*` | جميع اختبارات المتصفح، مع فحص وجود أصول السلع عند تغيير `brand/img`. |
| `vendor/*` | الخريطة المجسمة وواجهة الخريطة؛ أي استخدام جديد للمكتبات يحتاج توسيع الربط. |
| `pwa/*`، الأيقونات الجذرية، `manifest.webmanifest` | التحديث والغلاف والبداية بحسب المسار؛ لا توجد حاليًا حزمة متخصصة لاختبار كل تفاصيل تثبيت PWA. |
| `docs/*`، `src/README.md`، `brand/next/*`، ملفات توثيق الهوية | لا أثر تنفيذي حالي؛ أصول `next` للتسليم ولم تُدمج في اللعبة. إذا أُضيف تحميل مباشر منها يجب تغيير الربط. |

اختيار مجموعة جزئية لا يثبت سلامة جميع الأنظمة. تغيير معماري أو اعتماد جديد يستدعي تحديث الخريطة أو تشغيل الحزمة كاملة.

## سلامة التوازي

رُوجعت جميع ملفات الاختبار الحالية بحثًا عن `writeFile` و`appendFile` و`mkdir` و`screenshot` والمسارات المؤقتة وبدء الخوادم. لا توجد كتابة إلى ملف مؤقت واحد من اختبارين مختلفين في القائمة الحالية:

- `screens` يكتب لقطات `desktop/mobile-1...7`، و`lords` يستخدم `-8-lords...`، و`market` يستخدم `-m1...m3`، و`qty` يكتب `qty-mobile.png`.
- اختبارات `babylon-ui` و`cover` و`tutorial` و`guided` و`learn` و`lore-ui` و`journey-ui` تستخدم `/tmp/shots/`، لكن أسماء ملفاتها متميزة: `bab-` و`cover-` و`spot-` و`rest-card` و`learn-` و`lore-` و`j-`.
- كل اختبار متصفح يبدأ متصفحًا/سياقًا معزولًا؛ لا مشاركة للتخزين المحلي أو ملفات المستخدم. اختبار `update` يحجز منفذ HTTP تلقائيًا بدل رقم مشترك ثابت.
- لكل اسم اختبار سجل مستقل، والأسماء مكررة المصدر تُزال قبل جدولة العمليات.

لم يلزم تخصيص اختبار للتسلسل بسبب ملف مشترك. يتوفر `--serial` لتشغيل الحزمة أو مجموعة مرشحة بالتسلسل عند ضيق الموارد. لا تشغّل نسختين من المشغّل أو `all.sh` في الوقت نفسه، لأن أسماء سجلات `/tmp/t_*.out` توافق العقد الأصلي وتشترك بين التشغيلات المستقلة.

## فاحص النصوص

يفتح الصفحة المبنية الحالية دون تغييرها، ويفحص بيانات الدروس والشخصيات والحوارات والمهام وقصص الزعماء وأسرار المدن والحكايات والبطاقات والإنجازات والأخبار. يفحص الدول الخمس مع الشخصيات الخمس، وكل المدن الست عشرة، وعقد الحوارات المحلية ومخرجات `babFor` و`storyOf`. `Dialogs.DIALOGS` هو ناتج `cityDialogs` الفعلي عند تحميل المصدر، وليس نسخة اختبار بديلة.

تُفحص القوالب بعد التعويض المقصود في اللعبة: `{boss}` عبر `dlgView`، و`{م}` عبر `babFor`، وقوالب حكايات الجد عبر `storyOf`، و`{p}` بأول استبدال كما في `renderReact`، و`{اسم}` باسم لاعب معلوم. تُفحص كذلك الخيارات الحوارية المخفية بالشروط. لا يُحذف أي قالب مجهول لتجاوز الفحص.

ثم يفتح الشاشات التسع فعلًا، ويتحقق من مسار كل شاشة، ويقرأ `document.body.innerText` قبل محاكاة ثمانية أيام وبعدها لكل توليفة دولة وشخصية. يرفض اسم المدينة القديم، والقوالب الخام، و`undefined` و`null` و`NaN` و`[object Object]`، ويعرض مصدر المخالفة ونصها وقاعدتها. يرفض أيضًا أخطاء المتصفح.

الاستثناء الوحيد لاسم المدينة القديم هو **العنوان المطابق حرفيًا** «أغنى رجل في بابل» في تعليق المرجع التاريخي أول `src/babylon.js`؛ يذكر عنوان كتاب كلاسون لعام 1926. الاستثناء مقيد بالمصدر والنص معًا، ولا يسمح بالكلمة في أي نص ظاهر أو حوار. لا يُستثنى الملف كله.

## التحقق والقياسات

قياس فعلي في 2026-10-20 على ملفات اللعبة والقائمة من `178e958`، في البيئة نفسها بأربع أنوية متاحة. لم تتغير ملفات اللعبة أو الاختبارات بين التشغيلين. استُخدم Chromium المتاح، مع تكييف تشغيل محلي خارج المستودع لمسار Playwright وخدمة الصفحة عبر HTTP لتوافق المتصفح؛ استُخدم التكييف نفسه في التشغيلين ولم تتغير التأكيدات أو المهل. الأوقات تقريبية وتتأثر بحمل البيئة.

| التشغيل | الناجح | الفاشل | الزمن |
|---|---:|---:|---:|
| `sh test/all.sh` | 93 | 0 | 1195.6 ثانية (19 دقيقة و56 ثانية) |
| `node test/run.js --timing`، التوازي الافتراضي 4 | 93 | 0 | 473.7 ثانية (7 دقائق و54 ثانية) |

تطابقت **أسماء** الاختبارات الناجحة كلها، لا العدد وحده. التسريع 2.52 مرة وانخفاض الزمن 60.4%. كلا التشغيلين انتهى برمز خروج صفر. أبقى المشغّل مهلة 200 ثانية كما هي؛ كان `guided` أبطأ اختبار عند 196.7 ثانية، ويليه `map3d` عند 145.8 ثانية. اختبار الرحلة قريب من سقفه في هذه البيئة؛ يتوفر `--jobs 2` أو `--serial` إذا استنفد التشغيل المتوازي الموارد في بيئة أبطأ، دون زيادة المهلة أو تغيير الاختبار.

اجتاز المشغّل عشر مجموعات تحقق معزولة خارج المستودع: مرشحات الأسماء والتوقيت، علامات الفشل الثلاث ورمز خروج غير صفر، الخيارات غير الصالحة والمرشح الفارغ، عدم وجود تغييرات، تغييرات مرحّلة وغير مرحّلة، ملفات غير متتبعة، ملف مجهول يستدعي الكل، الحذف، فرق التوازي والتسلسل، وتمرير مهلة 200 ثانية ومعالجة انتهاء المهلة. تجربة المهلة استعملت أمر `timeout` بديلًا **في التجربة المؤقتة فقط** لتقصير الانتظار، وتحققت من تمرير القيمة 200؛ لم يُغيَّر أمر التشغيل المسلَّم.

اجتاز فاحص النصوص فحص 73,346 نصًا دون مخالفات في 54.0 ثانية. شملت الجولة 25 توليفة دولة وشخصية، والمدن الست عشرة، وأهداف الدروس العشرة، و450 قراءة للشاشات قبل المحاكاة وبعدها. وفي تجربة سلبية مؤقتة خارج المستودع حُقنت «بابل» في `Lessons.WELCOME[0].say` بعد تحميل الصفحة؛ خرج الفاحص بالرمز 1 وحدّد `src/lessons.js:WELCOME[0].say` والقاعدة والنص بدقة، مع مخالفة واحدة. لم تُعدَّل ملفات المصدر ولم تُرفع أداة الحقن. اختُبرت كذلك القوالب والقيم البرمجية وحدود الاستثناء الضيق. لا توجد مخالفات محتوى فعلية تحتاج إصلاحًا في هذه النسخة.

قبل الدفع دُمج تحديث تنظيم المصدر `47230d6`. تحقّقنا آليًا أن جمع أجزاء `src/engine/` و`src/ui/` بالترتيب يساوي المصدر الذي قيس أعلاه **بالبايت**. أُعيد البناء دون أي فرق في الملفات المتتبعة، وأضيف ربط المجلدات الجديدة، وأصبحت تقارير نصوص الشاشات تشير إلى ملفات `src/ui/` الحالية. أُعيدت الفحوص المتأثرة بعد الدمج: نجحت مجموعات `icons` و`numerals` و`screens` و`lords` و`market` و`tutorial` و`market2` و`market2-ui` كلها، ونجح فاحص النصوص النهائي مجددًا في فحص 73,346 نصًا بلا مخالفات، دون تعديل أي اختبار أو مصدر قائم.
