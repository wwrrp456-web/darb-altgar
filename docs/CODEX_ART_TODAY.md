# مهمة كودكس اليوم: توليد الصور فقط (بلا برمجة ولا دمج)

**القرار (2026-10-26):** لتخفيف التكلفة والحدّ، يتفرغ كودكس اليوم لتوليد الصور وتجهيزها ورفعها. **Claude يدمجها في اللعبة** ويكمل البرمجة. لا تعدّل أي ملف في `src/` أو `test/` أو `build.js`.

## اقرأ أولاً
`brand/STYLE.md` (الأسلوب)، `brand/PROMPTS.md` (قوالب التوليد)، `brand/ICONS.md`، `brand/ICON_TRANSPARENCY.md` (شفافية فعلية)، `brand/CHARACTERS.md`، `brand/IDENTITY.md`. المرجع الحالي هو `IDENTITY.md` ثم `STYLE.md`. وانظر `brand/img/` لما هو موجود فلا تكرره (مثلاً `hero/` فيه التاجر والصرّاف وقائد القافلة والحارس وصاحب الدكان وعمّ سالم بتعابيره).

## قواعد (غير قابلة للتفاوض)
- **بلا أي نص** داخل الصورة، لا عربي ولا إنجليزي ولا أرقام. الأسلوب مرسوم يدوياً بتظليل ناعم وحواف واضحة (لا كرتوني طفولي، لا فوتوغرافي)، وبالألوان في `STYLE.md`.
- الأيقونات والشخصيات **WebP بقناة alpha فعلية** (لا خلفية بيضاء/داكنة مدمجة). المشاهد JPG أو WebP.
- ثقافة وعصر مناسبان للدولة، بلا كاريكاتير ولا رموز دينية أو سياسية.
- ثبات الشخصية: استعمل `brand/img/hero/*` مرجعاً للأسلوب والنسب.
- **مجلد التسليم:** `brand/next/<المجموعة>/<id>.webp` (خارج البناء، لا يضخّم اللعبة). وحدّث `brand/next/MANIFEST.json`: لكل صورة `{id, path, width, height, alpha, usage, status:"ready|rejected", note}`.
- سجّل البرومت المستعمل لكل مجموعة في `brand/PROMPTS_GENERATED.md`.
- ارفع **كل مجموعة فور اكتمالها** (commit واحد لكل مجموعة)، ودمج `origin/main` قبل الدفع. إن اقترب حدّك: ارفع ما اكتمل واكتب سطراً في `docs/HANDOFF.md` بآخر مجموعة وما بقي.
- مراجعة ذاتية قبل الرفع: أصابع/أطراف سليمة، لا تشوّه، لا نصوص، قناة alpha نظيفة، الأسلوب متسق. ما رُفض يُعاد حتى مرتين ثم يُسجَّل `rejected` مع السبب.
