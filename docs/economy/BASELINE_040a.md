- بند `wealthLevy` = 0 «بعد» في الأحجام الثلاثة والنمطين.
- الخامل بعد الإلغاء: مليون −0.8٪ وعشرة ملايين −0.08٪ في السنة؛ الخسارة تكلفة التشغيل وحدها (أجور وصيانة)، لا شيء يُسحق. الخامل 100 ألف −7.95٪ لأن الأجور والصيانة (≈8.4 ألف) كبيرة نسبياً.

- التكاليف تتصاعد مع الأصول العاملة: مصروفات النشط عند 100 ألف 757 ألف (شراء بضاعة 589 ألفاً، ضرائب 69 ألفاً، جمارك، صيانة، أجور) وهي تنمو بنمو النشاط.

## تدقيق بنود المصروفات (`P.led.exp`: `pPay` و`payObligation` و`sink`)
| البند | السبب والمقابل |
|---|---|
| staff، wages، diwan، portm، regionalAgent | أجور عمال وقوافل ومصانع وسفن وإداريين وناظر الديوان وأمين الميناء ووكيل المنطقة: خدمة مقابلة |
| rent، upkeep، wear، agentUpkeep | إيجار الدكان وصيانة الأصول وبلى العربات: أصل أو نشاط فعلي |
| purchases، provisions، packs، farm | شراء بضاعة وزاد وأحمال وعمل المزرعة: سلع مقابلة |
| assets، hiring، foundCity، projects، mudarabaCap | شراء أصول وتوظيف وتأسيس مدينة ومشاريع كبرى ورأس مال مضاربة: يتحول إلى أصل |
| tax، customs، portfee | ضريبة المدينة على البيع وجمارك العبور ورسوم الميناء: مرتبطة بصفقة أو مرور |
| exportFee | نسبة من بيع المصنع المصدَّر (رسم تصدير): مرتبطة بعملية بيع |
| takaful، takafulFee، bankFee، exchange | تأمين وتكافل ورسوم مصرف وصرف: خدمة مقابلة |
| zakat، charity | زكاة وصدقة: معاملتها كما هي (خارج النطاق) |
| pact، pactFee، pactPenalty، pactShare، lobby، gift، tribute | عقود وهدايا وجباية وضغط عند الزعماء: ثمن علاقة أو عقد أو أتاوة حدث (قطع طريق) |
| fine | غرامة حدث (داهمة الضرائب عند تأجيل الزكاة أو إنقاذ مصنع): مرتبطة بفعل أو حدث |
| spoilage، storm، fire، bandits، shrink، sukukLoss، mudarabaLoss، waqfInvestmentLoss | خسائر أحداث ومخاطر استثمار: لا تُخصم بمعادلة |
| **wealthLevy** | **كان بلا مقابل: ملغى (LEVY.on=false)** |

**لا بند آخر يُخصم بمعادلة على الثروة بلا مقابل ظاهر.** ملاحظات للقرار اللاحق فقط (لم تُعدَّل): `exportFee` نسبة ثابتة من البيع، و`fine`/`tribute` أحداث عشوائية يتناسب مقدارها مع النقد أو قيمة الحمولة.
