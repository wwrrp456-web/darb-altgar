# قائمة التعديلات المتراكمة (تُنفَّذ دفعة واحدة بعد اعتماد البنود)

الحالة: «معتمد» = اتُّفق عليه وينتظر التنفيذ. «مقترح» = للنقاش. لا تنفيذ قبل أمر صريح بتنفيذ الدفعة.

## ١. تنظيف الشريط العلوي — معتمد

الهدف: إزالة التكرار وكل ما لا يخدم قراراً يتخذه اللاعب الآن، وتقليل ارتفاع الشريط (٢١٥px على الجوال حالياً إلى نحو ١٣٠–١٤٠px في البداية، وأقل من ١٠٠px على الحاسوب).

| العنصر | القرار |
|---|---|
| صورة اللاعب ومستواه | يبقى |
| شعار «درب التجّار» (حاسوب) | يُحذف |
| اللقب + شريطه | يُدمج مع الثروة في شريحة واحدة بشريط تقدّم واحد (نحو اللقب التالي) |
| الثروة + شريط الطور | تبقى في الشريحة المدموجة، وشريط الطور يُنقل إلى ملف التاجر |
| اليوم | يبقى بحجم صغير |
| الريال والحمولة | يبقيان دائماً |
| الدولار والذهب | يظهران من المستوى ٦ (فتح الصرافة) ولو كانا صفراً، ويظهران قبله إن وُجد رصيد |
| الدَّين / الحول | يبقى سطراً واحداً عند انطباقه |
| إيقاف / تشغيل / تسريع | تبقى |
| +١ يوم | يبقى بحجم أصغر |
| الصوت | يُنقل إلى قائمة (⋯) في الشريط |
| عمّ سالم | يبقى |
| زر طيّ الشريط وحالة الطي | يُحذفان (الشريط المصغّر المثبّت يؤدي الغرض) |
| نص «الوقت متوقف/يمضي» | يُحذف من الشيفرة |

التنفيذ المتوقع: `src/template.html` (هيكل وCSS الشريط) و`src/ui/04-header.js` و`src/ui/16-events.js`، وتحديث `hud`/`header-ledger`/`mini-ui`، مع إبقاء المعرّفات التي تعتمد عليها الاختبارات أو تحديث الاختبارات.
