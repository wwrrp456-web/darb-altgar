## 3) لحظتا الانتقال (ج5): خبر لمرة واحدة عند 40 و70
**الغرض:** اللاعب يرى الصورة تتغير ولا يعرف السبب؛ فيُقال له مرة واحدة. **لا رسم جديد ولا أيقونة** (قاعدة كودكس)، ولا مشهد احتفال 009 جديد؛ خبر نصي في «الأخبار» فقط.
- **المفتاح:** `AGEMOM = { on: true }` (ثابت جديد في `29-aging.js`؛ `AGEMOM.on=false` = لا خبر ولا حقل في الحفظ، والحلقة أدناه تُنفَّذ فقط إن `AGEMOM.on`).
- **الشرط (حرفاً)، داخل `checkLifeEvents(S)` في `src/engine/29-aging.js` وبعد سطر `if (S.legacy && S.legacy.retired) return;`:**
  ```
  if (AGEMOM.on) for (const at of [40, 70]) {
    if (age >= at && !(L.ageMoments || []).includes(at)) {
      (L.ageMoments = L.ageMoments || []).push(at);
      if (age - at < 1) news(S, LIFE_TEXTS.ageMoment[at === 40 ? 0 : 1]);
    }

  ```
  أي أن الحقل `L.ageMoments` يُنشأ عند أول عبور فقط، وحفظ قديم تجاوز العتبة يُسجَّل بصمت (`age - at >= 1`) فلا يتكرر الخبر ولا يفيض.
- **النصان (ثابتان، بلا مدلول ديني ولا حكم):**
  - `ageMoment[0]` (40): «بلغتَ الأربعين: خطّ الشيب في عارضيك، وصار الناس يسمّونك أبا التجّار. وجهك الجديد في ملفك.»

- **نقطة الوصول:** الخبر في شريط الأخبار القائم (نقرة واحدة)، والصورة نفسها في الشريط العلوي وبطاقة الملف.
- **«لا صوري»:** هذا خبر سردي يشرح تغيّر الصورة؛ لا ادّعاء أثر في الأرقام. ويُذكر ذلك صراحةً في التقرير.
