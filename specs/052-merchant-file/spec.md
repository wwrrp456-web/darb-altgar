## 3) كشوف الأداء وتنبيهات الخسارة (ملاحظة 33؛ KASHF)
### أ) الشهر والتراكم
`k(S) = floor(S.day / PR.month)` (30 يوماً، الثابت القائم). الحقل:
```
P.mx = { k, d0, led0:{inc:{…}, exp:{…}},          // لقطة الدفتر عند بداية الشهر
         t:{ [city]: { n, pl, nl, lb, ls, lt } },  // تجارة القوافل في مدينة البيع
         s:{ [shopId]: { c, rev, cogs, fix, g:{ [g]: rev } } },
         last: null | Statement,                    // الشهر المنتهي (واحد فقط)
         hist: [ { k, net } ] }                     // آخر KASHF.hist = 6 أشهر
```
- يُنشأ `P.mx` عند أول يوم بعد تفعيل المفتاح بـ`k = k(S)` و`d0 = S.day` ولقطة `P.led` (فالشهر الأول ناقص، ويُكتب «منذ يوم {d0}»).
- **تجارة القوافل** (في `logTrade` حين `side==='sell'` و`sector==='trade'`): `t[city].n += 1`، `t[city].pl += pl`، وإن `pl < 0`: `nl += 1`، `lb += lw.b`، `ls += lw.s`، `lt += lw.t` (§3-ب).
- **الدكاكين** (في `shopsDay`، لكل صنف بيع): `rev += gross − tax − cut − awayCut`، `cogs += cost0`، `g[g] += gross − tax − cut − awayCut`؛ ولكل دكان آخر اليوم `fix += حصته اليومية` بالمعادلة **نفسها حرفاً** التي يمررها الوقف إلى `recordShopNet` (السطر ~104):
```
shared   = (Δstaff + Δupkeep + Δrent + ΔmarketFee) − Δrent + deferredStaffCost        // فروق اليوم للمدينة
fix_day  = shared / max(1, ns) + (sh.rentPaid − rentBefore[sh.id]) + (Δ deferredWages لدَين إيجار الدكان)
net_day  = shopNets[sh.id] − fix_day
```
تُستخرج هذه الحسبة إلى دالة واحدة `shopFixDay(...)` يستعملها الوقف و052 معاً (لا نسخ)، ويبقى رقم الوقف كما هو حرفاً (اختبار).

### ب) سبب خسارة الصفقة (`lossParts`، `lossWhy`)
`logTrade` يأخذ معاملاً تاسعاً اختيارياً `tax`؛ يمرره `A.sell` (`24-advisor-actions.js` ~142) من `res.tax`. مع KASHF يُكتب `tr.tx = round(tax)` إن عُرف، وإن `pl < 0`:
```
cost = net − pl ;  uc = cost / q ;  us = (net + (tx ?? 0)) / q ;  m = mid(g)
lw.b = max(0, uc − m) × q          // اشتريتَها فوق السعر المعتاد
lw.s = max(0, m − us) × q          // بعتَها تحت السعر المعتاد
lw.t = tx ?? 0                     // ضريبة السوق
loss = −pl
السبب الأول = أكبر الثلاثة (التعادل: s ثم b ثم t)؛ وتُذكر معه الأجزاء التي ≥ KASHF.share × loss = 20٪
glut = c.stock[g] ≥ KASHF.glut × capG(c, g)   (يُقرأ بعد البيع؛ يُلحق بسبب s فقط)
```
`tr.lw = { b, s, t }` مقرّبة لأقرب ريال، و`tr.gl = 1` إن `glut`. النصوص (`lossWhy(S, tr)`):
- s: `بعتَها بـ{fmt(us)} للوحدة والمعتاد ≈ {fmt(m)}` + (`glut` ? `؛ السوق متخم بها` : '')
- b: `اشتريتَها بـ{fmt(uc)} للوحدة والمعتاد ≈ {fmt(m)}`
- t: `ضريبة السوق {fmt(lw.t)}`
- وإن كانت للقافلة خطة 050 (`car.bm` بـ`est > 0`) عند البيع: يُلحق `؛ قدّرنا ربحها ≈ {est} عند الانطلاق`.
- صفقة قديمة بلا `lw`: «لا تفصيل لهذه الصفقة».

**خبر الخسارة الكبيرة** (فوراً، لكل لاعب): إن `loss ≥ KASHF.big = 300` ولم تُطلق 032 بطاقة «أول خسارة» لهذه الصفقة نفسها: `news(S, '{مَن}خسرتَ {fmt(loss)} في بيع {q} {اسم g} في {city}: {lossWhy}.', 'bad')` حيث `مَن = diwanOf(S) ? 'الناظر: ' : ''`.

## 4) السمعة بأثر (ب7؛ REPX) — **حساسة: مراجعة Opus قبل التكامل**
### أ) سمعة التعامل (بلا الزكاة)
```
repT(S) = round( mean( score لأجزاء reputation(S).parts ذات id ≠ 'zakat' ) )      // أربعة أجزاء: inst، pacts، trust، mastery
repPactMul(S) = clamp( 1 + REPX.k  × (50 − repT) / 50 , 1 − REPX.k , 1 + REPX.k  )    // 0.90 … 1.10
repFinMul(S)  = clamp( 1 + REPX.kf × (repT − 50) / 50 , 1 − REPX.kf, 1 + REPX.kf )    // 0.75 … 1.25
```
**الزكاة مستبعدة** حتى لا يصير أداؤها سبباً لمكسب مالي (038 FR-005). `reputation()` نفسها و`quality` **لا تتغيران**.

### ب) أين يُطبَّق (سطر واحد محروس `REPX.on` في كل موضع)
1. **شروط عقود الزعماء القديمة** `pactTerms` (`05-haggle.js:41`): `m = clamp(1 − bs.trust/200, 0.6, 1.3) × perkMul(S,'pact') × disc × (REPX.on ? repPactMul(S) : 1)`. فيتغير `daily` و`upfront` و`share` (حصة الزعيم في شراكة الدكان) **عند التوقيع فقط**؛ العقد الموقَّع يبقى بشروطه. **`penalty` لا يمسّه** (045). عقود 036 خارج النطاق.
2. **حد القرض الحسن** (`24-advisor-actions.js:631`): `lim = round( min(FIN.qard.max, FIN.qard.base + FIN.qard.perTrust × max(0, bs.trust − FIN.qard.trust)) × (REPX.on ? repFinMul(S) : 1) )`. شرط الثقة الأدنى (20) كما هو. **القرض بلا زيادة كما هو.**
3. **حد تمويل المرابحة** (`24-advisor-actions.js:622`): `lim = max(0, netWorth(S) × FIN.mur.limit × (REPX.on ? repFinMul(S) : 1) − bankDebt(S))`، ورسالته `حدّ التمويل {floor(lim)} ريال ({round(100 × FIN.mur.limit × repFinMul)}٪ من ثروتك بسمعتك {repT}٪، ناقص ما عليك)`. **ربح المرابحة (`FIN.mur.terms`) لا يتغير**: يتغير الحد الذي يقبله البائع فقط، لا الثمن.

### ج) بطاقة السمعة في «أنا»
الأشرطة الخمسة كما هي، ويُوسَم شريط الزكاة `لا يدخل في الشروط`، ثم سطر الأثر بدل جملة «ستحدد جودة مصانعك لاحقاً»:
`سمعة التعامل {repT}٪: عقود الزعماء {sgnPct(repPactMul−1)} · حد القرض الحسن والمرابحة {sgnPct(repFinMul−1)} · جودة مصانعك {R.quality}٪` حيث `sgnPct(x) = (x ≤ 0 ? 'أرخص ' : 'أغلى ') + round(|x|×100) + '٪'` للعقود، و`(x ≥ 0 ? '+' : '−') + round(|x|×100) + '٪'` للحدود. وفي نافذة عرض العقد (القائمة) سطر `بسمعتك: {sgnPct}` إن ≠ 0.
