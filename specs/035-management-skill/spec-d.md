## 2) المعادلات حرفاً
### أ) القادة والنوخذة: طبقة فوق السقف (T030)
```
tierBonus(cp) = 0  إن لم يكن SKT.on أو لا cp.sk
              = 2  إن cp.sk.tr ≥ SKT.cap.t2 (360)
              = 1  إن cp.sk.tr ≥ SKT.cap.t1 (120)
              = 0  غير ذلك
sktEff(cp, k) = min(SKT.cap.max, cp[k] + tierBonus(cp))        k ∈ {trade, nav, combat}، و cap.max = 6
```
- مع `tierBonus = 0` النتيجة `cp[k]` نفسه (لأن `cp[k] ≤ 5 < 6`): **لا تغيّر قبل الرحلة 120.**
- **النمو `tr`** (عند الوصول، في `arrive` بعد سطر النمو القديم، وللنوخذة عند وصول رحلة بحرية بقائد السفينة `shipOf(S, car).captain`):
```
net_trip = car.pl − (cp.sk.pl0 ?? car.pl)         // ربح القافلة منذ آخر وصول لهذا القائد؛ أول مرة 0
cp.sk.tr += skM(net_trip)                        // skM من 035أ: 1 + 0.6·tanh(net/150) مقصوصة إلى [0.6، 1.6]
cp.sk.pl0 = car.pl
```
  فالقائد الرابح يبلغ +1 بعد ≈ 75 رحلة (m=1.6) والخاسر بعد 200 (m=0.6)؛ والخسارة تبطّئ ولا تُنزل أبداً (`tr` لا ينقص).
- **مواضع القراءة (وحدها؛ بدلها من `captain.k` الخام):**
  | الموضع | اليوم | بعد 035د |
  |---|---|---|
  | `navOf(car)` `09-travel.js:5` (سرعة 0.06، تلف السلع 0.1، العاصفة 0.1) | `captain.nav` | `sktEff(captain,'nav')` |
  | `defenseOf` `09-travel.js:117` | `captain.combat * 2` | `sktEff(captain,'combat') * 2` |
  | `autoRoute` `10-captains.js:57` ومساومة `24i-port-master.js:35` | `1 + 0.015 * captain.trade` | `1 + 0.015 * sktEff(captain,'trade')` |
  | `autoIndep` `10-captains.js:44` | `1 + 0.10 * captain.trade` | `1 + 0.10 * sktEff(captain,'trade')` |
  | `17-shocks.js:99` | `0.05 * captain.nav` | `0.05 * sktEff(captain,'nav')` |
  | `shipNav` و`seaExtra` `09b-sea.js:18،32` | `captain.nav`/`captain.combat` | `sktEff` للقائد نفسه |
- **الأجر لا يتغير:** `capWage` يبقى على المهارات الخام (لا أجر خفي على المكافأة)، فالتزام طويل الأمد يُكافَأ لا يُغرَّم.
- **السقف المالي:** لا أثر على ميزانية الشراء ولا على حدّ الإنفاق (`P.gold * 0.4/0.7`): الفرق في المساومة والدفاع والسرعة فقط.
- **الخبر:** عند بلوغ `tr` العتبة: `news(S, 'ترقّى القائد {الاسم}: صار بمهارته «فعّالاً» أعلى بدرجة بعد {tr} رحلة', 'good')` مرة واحدة (علامة `cp.sk.t1`/`t2` عددية 0/1).

### ب) الحرس: خبرة الفرقة `car.gx` (T032)
**الدرجة:** `g = gxGradeOf(xp)`: `g = 1` إن `xp < 12`، `g = 2` إن `12 ≤ xp < 40`، `g = 3` إن `xp ≥ 40` (`SKT.gx.need`). **لا ينزل `xp` ولا `g` أبداً.** وهي **فوق الرتب** (`GR`) لا بدلها: `gRanks` و`guardPower` و`guardWageUnits` تبقى كما هي.
**النمو** (يشترط `car.guards > 0` ويعمل مرة واحدة لكل حدث):
- `guardServed(car)` (`30d-guards.js`: وصول محروس سالماً بلا هزيمة وبلا طريق مفتوح): `car.gx.xp += SKT.gx.safe` (= 1).
- في `banditFight` فرع الصدّ (`defense >= B`): `car.gx.xp += SKT.gx.repel` (= 3) **مرة** لكل صدّ (بما فيه القراصنة).
- الهزيمة: لا زيادة ولا نقص (`guardDefeat` يصفّر `svc` وحده كما اليوم).
**الأثر (حقيقيان، بحسب `g`):**
1. **خسارة الهزيمة** في `banditFight` (`09-travel.js:122`) بعد حساب `f` الحالي (`ftxFirstLoss(...)` مضروباً في `perkMul('banditLoss')`) وقبل حساب `lost`:
```
f = f × (1 − SKT.gx.cut[g−1])         // g=1: ×1؛ g=2: ×0.85؛ g=3: ×0.85    (فقط إن SKT.on && car.guards > 0 && car.gx)
```
   فالنهب الأساسي `U(0.15، 0.40)` يصير بعد الخبرة `U(0.1275، 0.34)` تقريباً. والتكافل (`tkClaim`) يعوّض `lost` **الفعلي بعد الخفض** (لا تعويض عمّا لم يُنهب). **لا شرط جزائي ولا مكوّن ضرر جديد في `actualDamage`** (045): هذا خفض نهب لا تعويض.
2. **الدفاع** في `defenseOf`:
```
defenseOf(car) = (guardPower(car) × SKT.gx.pow[g−1] + car.crew × 0.4 + sktEff(captain,'combat') × 2) × (guardMorale(car) / 100)
              g=3 ⇒ pow = 1.10؛ g=1,2 ⇒ pow = 1
```
   و`roadEstimate` يقرأ `defenseOf` فيتحسّن **تقدير أمان الطريق تلقائياً بقدر الأثر الفعلي** (لا رقم منفصل). ويُضاف إلى ما يعيده: `cut: SKT.gx.cut[g−1]` (يعرضه سطر الطريق: «خبرة الحرس تخفض النهب 15٪»).
- **لا يمس:** احتمال الهجوم، قوة العصابة `B`، رتب الحرس وأجورها، رئيس الحرس (+10 معنويات).

### ج) الطاقم: خبرة `car.cx` (T033)
**الدرجة:** `g`: 1 إن `xp < 60`، 2 إن `60 ≤ xp < 200`، 3 إن `xp ≥ 200` (`SKT.cx.need`). لا تنزل.
**النمو:** في `20-finance.js` فرع `car.left > 0`: كل يوم طريق وفيه `car.crew ≥ 1`: `car.cx.xp += 1` (مرة لكل قافلة في اليوم).
**الأثر:**
```
معنويات يوم الطريق:   car.morale = max(0, car.morale − (car.hungry ? 3 : 0.8) × (1 − SKT.cx.moraleCut[g−1]))
                       g=2,3 ⇒ 0.6 يومياً (و2.25 إن جائع)؛ g=1 ⇒ 0.8 (و3)
مؤن يوم الطريق:        car.supplies = max(0, car.supplies − car.crew × 0.12 × (1 − SKT.cx.supplyCut[g−1]))
supplyNeed(car,days)   = ceil( (car.crew × 0.12 × (1 − SKT.cx.supplyCut[g−1]) + fodderDay(car)) × days )     // ليتطابق التخطيط والاستهلاك
                       g=3 ⇒ 0.108 للفرد؛ g=1,2 ⇒ 0.12
```
- **أثر المعنويات حقيقي:** تحت 40 تسقط السرعة 15٪ (`09-travel.js:7`)، وتحت `CHIEFC.moraleMin` يتدخل شيخ القوافل، ودفاع القافلة مضروب في `guardMorale/100`.
- **لا أجور ولا حدّ جديد.** (لا «تسريع تحميل» ولا «استهلاك عربات»: §0-3.)

## 4) الواجهة (قاعدتا الوصول والظهور)
- **بطاقة الكفاءة الموحّدة (`skillCardHTML`، 035أ)** تُعرض أيضاً لـ: القائد والنوخذة (دورهم «قائد»/«نوخذة»)، شيخ القوافل، الشهبندر. تُضاف إلى `SKILL.next` سطور المفاتيح `captain`/`cchief`/`portm` (نص ما تفتحه الدرجة، مثل «يرفع مهارته الفعّالة +1 بعد 120 رحلة»). وبطاقة القائد تُظهر **شريطاً ثانياً** «نحو التمييز: {tr} / 120» (ثم / 360) وسطراً «المهارة الفعّالة: تجارة {a} ملاحة {b} قتال {c}» (من `sktEff`).
- **الحرس والطاقم:** سطران في بطاقة القافلة (تبويب «الأعمال»، نقرة واحدة من الرئيسية): `🛡 {names.gx[g−1]} · {xp}/{need}` و`🎒 {names.cx[g−1]} · {xp}/{need}` بشريط تقدم، **وما يفتحه كل منهما بالأرقام** («الدرجة 2: ينقص النهب 15٪ بعد الهزيمة»). **لا أيقونة جديدة**؛ تُستعمل `guard-ranks-*` المربوطة في 049 أو الإيموجي القائم.
- **نقطة الوصول:** الرئيسية ← الأعمال (نقرة) ← بطاقة القافلة (الحرس والطاقم والقائد: نقرة ثانية على الشارة)، والترقيات تأتي **خبراً** (`news`) ويظهر في «اليوم»؛ وعند ترقية درجة حرس/طاقم/شيخ/شهبندر تُضاف بطاقة «المطلوب» **معلوماتية** لمرة واحدة (`id: 'skt:' + key`، `w: 40`، زرها «افتح بطاقته»).
- **ظهور الاختيار:** لا اختيار جديد.

## 5) ما لا يمسّه هذا العمل
- `capWage` وأجور الحرس والطاقم والشيخ والشهبندر؛ رتب `GR` وأسعارها؛ احتمال الهجوم وقوة العصابة؛ ميزانيات الشيخ والشهبندر وسقوفها؛ أي حكم شرعي أو زكاة (وعاء الزكاة يُحسب على ما يملكه التاجر؛ ما يتغير هنا مقدار ما يُنهب فحسب)؛ عقود الزعماء والامتياز؛ `actualDamage` و`PEN_PARTS` (لا مكوّن جديد).
- ترتيب الأحداث العشوائية: **لا استدعاء `rnd`/`rr` جديد** (`sktDay` ومعادلات §2 حتمية)، فتبقى بذور المحاكاة هي نفسها بين المفتاحين ما دام المفتاح مطفأً، وتتغير بالنتائج لا بسحب جديد حين يُشغَّل.
