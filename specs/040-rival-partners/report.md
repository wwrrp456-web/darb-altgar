## جدول «لا صوري» (§14): ما يظهر ← الرقم ← أين
- عرض مقبول ← `P.gold −= cap` أو `K−boss` و`rv.w` يتحرك ← نافذة العرض وبطاقة المنافس (ثروته دقيقة للحاكم).
- قيد شهري ← `pnl += cap × k×(w1−w0)/w0` ← تقرير العقود «نسب آخر الشهور».
- خفة الضغط ← `rgScale × 0.65` ← سطر «ضغطه أخفّ 35٪» وسعر المخزون.
- زيادة الصندوق ← `+0.5×12×str×sp` يومياً ← سطر «يزيد X ريالاً يومياً» (X من المحرك).
- انتهاء العقد ← `P.gold += back′` و`P.agrLog` ← خبر بالحصيلة و«آخر الحصائل» وخبر شهري.
- الزكاة ← `zk += cap` (rmud) ونصيب الشريك من الربح يُخصم (rpart) ← نص ZK-01 حرفاً في النافذة، واختبار zakat.

- **الخطأ:** العرض الوارد للمضاربة كان يفشل قبوله ('اختر رأس مال من الخيارات') حين لا يكون `mudCap` هو القيد، ويفشل محوّل `rvpart` معه. **الإصلاح:** في `30h2p-rival-partner.js` الأهلية للعرض الوارد تفحص `100 ≤ cap ≤ rvpCapMax` بدل الخيارات، وإلا 'تغيّرت ثروته فلم يعد العرض قائماً'. الاختبار يضبط `rvx.w = 15000` ويستعمل `cap = min(rvpCapMax, round100(askW×w))`؛ فشل قبل الإصلاح ونجح بعده.
