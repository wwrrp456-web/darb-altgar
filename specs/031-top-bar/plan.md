# Implementation Plan: الشريط العلوي الحديث (031)

## القرارات
- **D1 — الملفات:** العرض في `src/ui/04-header.js` (`renderHeader` ونحوه) والهيكل والتنسيق في `src/template.html` (`#top`, `.hud1`, `.hud-av`, `.hbar-group`, `.hud2`). لا تعديل في المحرك ولا `src/engine.js`.
- **D2 — الهيكل:** `#top` يصير ثلاث مناطق: (أ) بطاقة الهوية: إطار الشخصية `#hAvatar` + اسم الرتبة `#hTitle` + شريط `#hProg`؛ (ب) شارة الثروة `#hNW` (ذهبية)؛ (ج) صف كبسولات `.hcaps`: ريال، حمولة، ثم دولار/ذهب/فضة/دَين/حول حين تظهر. المعرّفات القائمة تبقى لئلا يُكسر اختبار أو مرشد (FR-003).
- **D3 — الكبسولة:** مكوّن واحد `capsule({id, icon, text, plus})` يُنتج `<button class="hcap" data-act="resource" ...>` + زراً مجاوراً `<button class="hcap-plus" aria-label="…">`؛ الأرقام بـ`hudShort`. الكبسولة تستعمل `resourceMenu` القائم دون تغيير.
- **D4 — وجهة «+»:** دالة `plusTarget(key)` بالسياق: الريال → الحصّالة إن كان فيها رصيد أو الصرافة (`go('cities')` + `ct='fx'`) وإلا السوق؛ الحمولة → `go('market')`. لا فعل جديد في المحرك.
- **D5 — الإطار:** CSS خالص أولاً (حد ذهبي وحلقة التقدّم القائمة `.ring`)؛ وإن رسم Codex إطاراً (WebP بشفافية، بلا نص) يُضاف في `brand/img/ui/` ويُدمج تلقائياً. المنفّذ لا يرسم.
- **D6 — الرجوع:** `const TOPBAR = { on: true }` في `00-state.js`؛ إن كان `false` يُرسم الرأس القديم من الشيفرة القائمة (تُحفظ دالة العرض القديمة كما هي خلف الشرط). التبديل لا يمس الحفظ ولا `darb-ui`.
- **D7 — الأداء:** مفتاح تغيّر `dataset.k` لكل منطقة (كنمط `hAvatar`/`fdock`) فلا يُعاد بناؤها بلا تغيّر، وقياس `renderHeader` قبل/بعد (SC-005).
- **D8 — الوصول:** لكل كبسولة و«+» `aria-label` عربي؛ ترتيب التركيز هوية ← ثروة ← كبسولات ← وقت.
