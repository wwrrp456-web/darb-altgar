# خريطة الشيفرة

اللعبة تُبنى بـ`node build.js` إلى `index.html` واحد. الشيفرة مقسّمة حسب الميزة، وتُدمج الأجزاء بالترتيب الرقمي لأسمائها داخل نطاق واحد (لا وحدات ES)، فالدوال والثوابت مشتركة بين أجزاء المجلد الواحد.

## المحرك: `src/engine/` (بلا واجهة، يعمل في المتصفح وNode)
`src/engine.js` **ملف مولَّد** من الأجزاء عند كل بناء (تحتاجه اختبارات Node عبر `require`). لا تعدّله؛ عدّل الأجزاء.

## الواجهة: `src/ui/`، 08b-pageorder (تنظيم الصفحات 033ب: السوق والقافلة والزعماء والأكاديمية والرئيسية)

## بيانات ونصوص ووحدات مستقلة

## قواعد
- إضافة جزء جديد: ملف برقم يحدد موضعه في الترتيب، لا يغيّر شيئاً آخر.
- كل جزء يُقتطع من الملف الأصلي حرفياً، فترتيب الدمج هو ترتيب الشيفرة الأصلي. لا تنقل شيفرة بين الأجزاء دون التأكد أن ما تستعمله معرَّف قبلها وقت التنفيذ.
