# خريطة الشيفرة

اللعبة تُبنى بـ`node build.js` إلى `index.html` واحد. الشيفرة مقسّمة حسب الميزة، وتُدمج الأجزاء بالترتيب الرقمي لأسمائها داخل نطاق واحد (لا وحدات ES)، فالدوال والثوابت مشتركة بين أجزاء المجلد الواحد.

## المحرك: `src/engine/` (بلا واجهة، يعمل في المتصفح وNode)
`src/engine.js` **ملف مولَّد** من الأجزاء عند كل بناء (تحتاجه اختبارات Node عبر `require`). لا تعدّله؛ عدّل الأجزاء.

| الجزء | المحتوى |
|---|---|
| 00-head | الإعداد الأولي والاستيرادات |
| 01-data-world | الدول والسلع والمدن |
| 02-core-world | العشوائية البذرية، المحاسبة، تكوين العالم |
| 03-prices | الأسعار والمخزون |
| 04-bosses، 05-haggle | زعماء الأسواق والشراكات، المساومة |
| 06-estate، 07-farm | العقارات والعمّال، المزرعة |
| 08-trade، 09-travel | الشراء والبيع، الرحلات |
| 10-captains، 11-day | القادة، خطوة اليوم |
| 12-agents، 13-factories | الوكلاء، المصانع |
| 14-dialogs، 15-rival، 16-seasons، 17-shocks، 18-butcher | الحوارات، المنافس، المواسم، الصدمات، الملحمة |
| 19-player، 20-finance، 21-orders | اللاعب، التمويل المشروع، الأوامر |
| 22-learn، 23-zakat | التعليم، الزكاة |
| 24-advisor-actions | المستشار وكائن الأفعال `A` |
| 25-quotes، 26-stress، 27-save | التسعير التقديري، اختبار الضغط، الحفظ |
| 28-achievements، 29-cards، 30-freeplay | الإنجازات، البطاقات، اللعب الحر |
| 31-api | واجهة التصدير |

## الواجهة: `src/ui/`
state (الحالة المشتركة)، save، learn (عمّ سالم والمستويات)، time-routing، header، scenes-deals، screen-home/map/market/caravan-estate/lords/empire/cities، guide-mission (الجولة ومهمة عمّ سالم)، salem-notebook، render (الرسم والطبقات)، events (النقرات)، dev-autopilot (المطوّر والتشغيل التلقائي)، boot.

## بيانات ونصوص ووحدات مستقلة
`lessons.js` `lore.js` `babylon.js` `dialogs.js` `achievements.js` `cards.js` (بيانات)، `world-map.js` `map3d.js` `sound.js` `savecode.js` `icons.js` (وحدات)، `template.html` (الهيكل والأنماط).

## قواعد
- إضافة جزء جديد: ملف برقم يحدد موضعه في الترتيب، لا يغيّر شيئاً آخر.
- كل جزء يُقتطع من الملف الأصلي حرفياً، فترتيب الدمج هو ترتيب الشيفرة الأصلي. لا تنقل شيفرة بين الأجزاء دون التأكد أن ما تستعمله معرَّف قبلها وقت التنفيذ.
